# Interview prep — CampusConnect — Student & Placement Management API

Be able to answer without reading:
1. What problem does this project solve?
2. Why Spring Boot and REST APIs?
3. Explain Controller, Service, Repository, Entity, and DTO.
4. How does request validation work?
5. What does pagination solve?
6. Why are API errors handled centrally?
7. What does `@Transactional` do?
8. What is JPA and how does it map Java objects to database tables?
9. How did you test the service layer?
10. What would you change before production?

Only claim features you have run and understand. This is a starter portfolio implementation: run it, verify the endpoints, review the code, and add your own improvements before presenting it in interviews.
